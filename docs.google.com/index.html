Google Docs App Tools

Google ドキュメントの生産性を向上させるユーザースクリプト集です。Gemini エクスポート連携の最適化など、スムーズなワークフローを実現します。

  • Gemini Exported Docs Auto-Closer ⏱️

    Gemini Artifact Exporter によって自動的に開かれた Google ドキュメントのタブを、一定時間後に自動で閉じてブラウザのフォーカスを Gemini に戻します。

    Install
  • Auto Paste in New Tab 📋

    Google Docs上で新しいタブを開き、クリップボードの内容を自動でペーストするスクリプトです。

    Install (v0.1.5)
