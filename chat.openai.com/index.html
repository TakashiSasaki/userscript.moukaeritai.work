ChatGPT App Tools

OpenAI ChatGPT の体験をより快適に。会話統計、バッジ表示、自動化、検索機能などの高品質なユーザースクリプト集です。

  • Turn Counter 🔢

    ChatGPT の会話で、ユーザーとアシスタントのターン数、画像数、文字数、コードブロック数をリアルタイムに計測・表示します。

    Install (v0.2.8)
  • Profile Badge 📛

    ChatGPT のプロファイル覧に、好きな絵文字やテキストでカスタムバッジを表示します。複数のバッジ設定にも対応。

    Install (v0.2.6)
  • Conversation Lister 📋

    会話履歴のタイトルと ID を取得し、検索や TSV 形式でのリスト化を可能にします。大量の会話を整理するのに最適です。

    Install (v0.8.3)
