ChatGPT Canvas Exporter

ChatGPTの「Canvas」機能で作成されたドキュメントを、画像データごとワンクリックで一括エクスポートする強力なユーザースクリプト。

📝
Markdownエクスポート
作成中のキャンバスや過去の特定のキャンバスを、扱いやすいMarkdown形式でPCに即座に保存します。
📦
画像込みのフルZIP一括保存
会話スレッド内のすべてのキャンバスと、会話内で使用された画像を横断的に収集・分析し、一つのZIPファイルにまとめてエクスポートします。
⚡
安全・高速な同期処理
Tampermonkey等によるサンドボックス制限を突破するため、Base64への変換とネイティブJSライブラリ（fflate）による完全同期型のZIP処理を実現しました。処理中のフリーズを防ぎます。
⚙️
ユーザーUIの最適化
画面に追従するフローティングボタンを追加。独自の管理パネルでエクスポートを一元管理し、ボタンの配置（ドラッグ移動）や直前の位置もブラウザ内で自動保存されます。
