# Agent開発のためのHTMLサンプル前処理ガイド

## 1. 目的

このドキュメントは、コーディングエージェントがHTMLサンプルファイルを扱う際の標準的な手順とルールを定めます。
目的は、ユーザースクリプト開発の基盤となるHTMLサンプルを、以下の状態に保つことです。

- **軽量であること:** 不要な情報を取り除き、ファイルサイズを削減する。
- **構造が明確であること:** セレクタの決定に不要なノイズ（インデント、コメント等）を排除する。
- **一貫性が保たれていること:** 常に同じルールセットに基づいて処理され、再現性がある。

すべてのエージェントは、HTMLサンプルファイルを扱う際にこのガイドに従ってください。

## 2. 開発ワークフロー

HTMLサンプルファイル（`.html`）を編集、またはこのファイルを基に開発を行う場合は、必ず以下の手順に従ってください。

### 手順1: ファイルの初期化

作業を開始する前に、対象のHTMLファイルがリポジトリの最新の状態（前処理済み）になっていることを確認します。しかし、前処理スクリプトの検証や変更を行う場合は、まず対象ファイルを**最初にコミットされた時点のオリジナル状態に復元**する必要があります。

```bash
# ファイルをHEADの状態に戻す場合
git restore path/to/your/file.html
```

### 手順2: 前処理の実行

HTMLファイルに対して、このディレクトリにある `preprocess_html_samples.py` スクリプトを実行します。このスクリプトは、後述する「3. 前処理ルール」を適用します。

スクリプトはコマンドライン引数として、処理対象ファイルのglobパターンを受け取ります。

```bash
# samplesディレクトリ内のすべてのhtmlファイルを処理する場合
./preprocess_html_samples.py 'samples/*.html'

# 特定のファイルを処理する場合
./preprocess_html_samples.py 'samples/your_specific_file.html'
```

### 手順3: 変更のコミット

前処理によってHTMLサンプルファイルに変更が加えられた場合は、その変更をリポジトリにコミットしてください。これにより、他のエージェントや開発者は常に最新化されたサンプルを利用できます。

```bash
git add .
git commit -m "docs: Preprocess HTML samples with the latest script"
```

## 3. 前処理ルール

`preprocess_html_samples.py` スクリプトは以下のルールを適用します。

1.  **属性の削除**
    - **空の属性値を持つ属性のみを削除:** `style=""` や `class=""` のように、値が空文字列である属性のみを削除します。

2.  **要素の削除・内部コンテンツのクリア**
    - **`<head>`要素内の不要な要素を削除:** `<link>`, `<meta>`, `<title>`などを削除します。
    - **`<script>` および `<style>` 要素の削除:** 文書内のすべての`<script>`, `<style>`タグを削除します。
    - **`<svg>` 要素の子要素を削除:** `<svg>` タグ自体は維持し、その子要素（`<path>`, `<g>`, `<use>` など）をすべて削除します。
    - **HTMLコメントの削除:** `<!-- ... -->` をすべて削除します。

3.  **コンテンツの短縮**
    - **長いテキストノードの短縮:** 要素内のテキストが100文字を超える場合、最初の100文字を残して `...` を追記します。

4.  **フォーマット**
    - **インデントなしの整形:** 処理後のHTMLは、要素に基づいた改行は維持しつつ、各行の先頭にあるインデント用空白は除去した形式で出力します。

## 4. スクリプト仕様

- **実装:** Pythonとライブラリ `BeautifulSoup4` (`bs4`) を用いて実装されています。
- **冪等性:** このスクリプトは冪等性を持つように設計されており、処理済みのファイルに対して再度実行しても、ファイルの内容に変更は加わりません。
- **実行環境:** スクリプトを実行するには `python3` と `beautifulsoup4`, `lxml` が必要です。

```python
# スクリプトの出力フォーマット部分の実装例
```
