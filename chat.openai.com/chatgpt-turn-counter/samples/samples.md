# サンプルHTMLファイルの前処理

samples ディレクトリには多数のHTMLファイルがサンプルとして保存されている。
いくつかのHTMLファイルはサイズが大きいため、不要な部分を除去する前処理を行う。

前処理には Pythonスクリプトを一時的に作成して行うことができる。
不足しているPythonパッケージがあればpipを使用してよい。


## 前処理のための事前調査
各HTMLファイルについて、
DOMをパースして、テキストノードの長さの分布、Scriptタグの数、Styleタグの数、コメントノードの数を表示する。
事前調査の結果は samples-analysis.md に記録する。

# 長いテキストノードのトランケート
テキストノードの長さを1000文字未満にトランケートする。

# 空文字属性の削除
style="" のように空文字が値として指定されている属性は不要なので削除する。

# コメントノードの削除
コメントノードは削除する。

# Scriptタグの削除
Scriptタグは削除する。

# Styleタグの削除
Styleタグは削除する。
