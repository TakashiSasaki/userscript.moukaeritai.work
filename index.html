Moukaeritai Userscripts

  • お名前.com DNSレコードバックアップ 💾

    お名前ドットコムのDNSレコード設定ページからリソースレコード(RR)を自動的に記録・バックアップします。

    Install (v0.0.6)

  • お名前.com 邪悪広告ブロッカー 🛡️

    お名前.com Navi の操作を妨げる「邪悪な」広告や確認ポップアップ、チャットサポート等を自動的に非表示にします。

    Install (v0.1.12)

  • ChatGPT Turn Counter 🔢

    ChatGPTの会話で、ユーザーとアシスタントのターン数、画像数、文字数、コードブロック数をカウントし、画像をDataURLとしてコピーする機能を提供します。

    Install (v0.2.8)

  • ChatGPT Profile Badge 📛

    ChatGPTのユーザープロファイルに、好きな文字列や絵文字でカスタム「バッジ」を追加します。

    Install (v0.2.6)

  • ChatGPT Conversation Lister 📋

    会話履歴のタイトルと ID を取得し、検索や TSV 形式でのリスト化を可能にします。大量の会話を整理するのに最適です。

    Install (v1.0.15)

  • Gemini Profile Badge 📛

    Google Geminiのユーザープロファイルに、好きな文字列や絵文字でカスタム「バッジ」を追加します。

    Install (v0.1.7)

  • Grok Conversation Copy 📋

    Grokの会話ページで、全てのコピーボタンを順に押して内容を結合し、クリップボードにコピーします。

    Install (v1.3.6)

  • Gemini One Click Delete 🗑️

    Google Gemini の会話をワンクリックで削除する機能を提供します。

    Install (v0.1.15)

  • Gemini Export to Docs 📄

    Google Gemini の会話やキャンバスを、ワンクリックで Google Docs にエクスポートするユーザースクリプトです。

    Install (v0.1.21)

  • Gemini Artifact Exporter 📦

    Gemini のサイドバーにある Article アーティファクトをまとめて Google Docs にエクスポートします。

    Install (v0.1.14)

  • Gemini Auto-Scroll 📜

    Google Gemini のサイドバー（会話リスト）を無限に自動スクロールし、すべての会話履歴を一括でロードするためのユーザースクリプトです。

    Install (v0.1.37)

  • Gemini Turn Counter 🔢

    Google Gemini 上での会話において、メッセージ数（ターン数）、文字数、画像数をリアルタイムにカウントし表示します。

    Install (v0.1.16)

  • Gemini Search Snippet Helper 🔢

    Gemini の検索結果一覧において、各会話カードのタイトルに連番を表示し、視認性と識別性を向上させるユーザースクリプトです。

    Install (v0.1.4)

  • YouTube Playlist Saver 📺

    YouTubeプレイリストの動画IDを記録・管理。フィルタリング等のUI機能は独立したスクリプトに分離されました。バックグラウンドで動作します。

    Install (v0.2.53)

  • YouTube Playlist Scroller 📜

    YouTubeプレイリストを自動的にスクロールし、大量の動画があるリストの読み込みを支援します。バックグラウンド動作にも対応。Saverと併用して利用できます。

    Install (v0.1.8)

  • YouTube Playlist Filter 🔍

    プレイリストのフィルタリング、スキャン済み範囲（Range）の状態表示を提供します。Saverと連携して動作します。

    Install (v0.1.14)

  • YouTube Playlist Remover 🗑️

    プレイリスト内の不要な動画（視聴済みの動画など）を一括削除するツール。フィルタと連携して安全に削除できます。

    Install (v0.1.39)

  • YouTube Playlist Lite ⚡

    プレイリストのサムネイルを非表示にして軽量化するツール。大量の動画があるリストの操作を快適にします。

    Install (v0.1.11)
