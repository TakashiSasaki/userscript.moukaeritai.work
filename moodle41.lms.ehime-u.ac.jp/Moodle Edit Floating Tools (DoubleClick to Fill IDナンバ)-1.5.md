# Moodle Edit Floating Tools (DoubleClick to Fill IDナンバ)

## スクリプト概要

このTampermonkeyユーザースクリプトは、Moodleの質問編集ページ（`https://moodle41.lms.ehime-u.ac.jp/moodle/question/bank/editquestion/question.php*`）のユーザーインターフェースを強化します。画面右上に固定されたフローティングツールバーを追加し、保存/キャンセルアクションへの迅速なアクセスと、「IDナンバ」入力フィールドの機能拡張を提供します。

## 主な機能と動作

-   **フローティングツールバー**: 画面の右上隅に固定された`div`要素（`#moodle-edit-floatingtools`）を挿入します。このツールバーは、背景色、影、パディング、レイアウト（フレックスボックス）などのスタイルが適用されており、視覚的に目立ち、機能的です。また、異なる画面サイズに対応するためのレスポンシブデザインも含まれています。
-   **IDナンバ入力フィールドの強化**:
    -   **永続性**: スクリプトは、`GM_setValue`と`GM_getValue`を使用して、セッションを跨いで最後に使用された「IDナンバ」の値を記憶します。
    -   **以前の値のプレースホルダー表示**: 現在の「IDナンバ」入力フィールドが空の場合、最後に使用された値がプレースホルダーとして表示されます。
    -   **ダブルクリックで入力**: 拡張された「IDナンバ」入力フィールドが空で、プレースホルダーが表示されている場合、フィールドをダブルクリックすると、プレースホルダーの値（最後に使用されたIDナンバ）が自動的に入力されます。これにより、元のMoodle入力フィールドとの値も同期され、`input`イベントがディスパッチされます。
    -   **同期**: 拡張された入力フィールドと元のMoodleの「IDナンバ」入力フィールドは双方向で同期されます。
    -   **スタイリングの改善**: フローティングバー内の入力フィールドは、読みやすさとより広い入力領域のためにスタイルが調整されています。
-   **プロキシ保存/キャンセルボタン**: フローティングツールバーには、「保存」と「キャンセル」ボタンが含まれており、これらはMoodleの元の保存ボタン（`#id_submitbutton`）とキャンセルボタン（`#id_cancel`）のプロキシとして機能します。これらのプロキシボタンをクリックすると、元の要素の対応するアクションがトリガーされます。「保存」プロキシは、現在の「IDナンバ」がローカルストレージに保存されることも保証します。
-   **CSSの注入**: `GM_addStyle`を使用してカスタムCSSを注入し、フローティングバーとそのコンポーネントが正しくスタイル設定され、レスポンシブであることを保証します。

## スクリプトの目的

このスクリプトは、Moodleの教師や管理者、特に「IDナンバ」フィールドの管理に関して、質問を編集する際のワークフローとユーザーエクスペリエンスを大幅に改善することを目的としています。

## 技術詳細

-   **Tampermonkey API**:
    -   `GM_addStyle`: カスタムCSSをページに適用するために使用されます。
    -   `GM_setValue`, `GM_getValue`: 最後に使用された「IDナンバ」の値を永続的に保存および取得するために使用されます。
-   **DOM操作**: `document.getElementById`, `cloneNode`, `querySelector`, `addEventListener`, `createElement`, `appendChild`, `dispatchEvent`などを用いて、ページ要素の検出、複製、追加、イベントリスナーの設定、イベントの発火を行います。
-   **非同期処理**: `setTimeout`と`async`/`await`を使用して、DOM要素が完全にロードされるのを待ち、スクリプトの注入を試みます。

## 使用方法

1.  Tampermonkeyまたは同様のユーザースクリプトマネージャーをブラウザにインストールします。
2.  このスクリプトをインストールします。
3.  Moodleの質問編集ページ（例: `https://moodle41.lms.ehime-u.ac.jp/moodle/question/bank/editquestion/question.php`）にアクセスします。
4.  ページ右上にフローティングツールバーが表示されます。
5.  ツールバー内の「IDナンバ」入力フィールドは、最後に使用された値をプレースホルダーとして表示します。
6.  空の「IDナンバ」入力フィールドをダブルクリックすると、プレースホルダーの値が自動的に入力されます。
7.  ツールバーの「変更を保存する」または「キャンセル」ボタンを使用して、質問の編集を完了します。
