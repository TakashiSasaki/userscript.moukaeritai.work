# M365 Copilot One-Click Delete

## 概要 (Overview)
Microsoft 365 Copilot (`m365.cloud.microsoft/chat/`) のUIにおいて、現在アクティブな会話をワンクリック、またはショートカットキー (`Ctrl + Shift + Backspace`) で削除できるユーザースクリプトです。

デフォルトのUIでは、「その他」メニューを開いてから「削除」を選択し、さらに確認ダイアログで「削除する」をクリックする必要がありますが、このスクリプトはこれらの一連の操作を自動化します。

## 機能 (Features)
- **フローティングUI**: 画面右下に表示されるコンパクトなパネルから、ワンクリックでアクティブなチャットを削除できます。
- **ショートカットキー**: `Ctrl + Shift + Backspace` に対応しており、キーボードから手を離さずに削除を実行できます。
- **ステータス表示**: 削除処理中はボタンが非活性になり、重複実行を防ぎます。

## インストール
ルートディレクトリの `index.html` からインストールできます。マネージャーは Tampermonkey を推奨します。

## 互換性について
対象サイトのDOM変更により、セレクタが合わなくなった場合は動作しなくなる可能性があります。その際は `AGENTS.md` のセレクタ情報を更新する必要があります。
