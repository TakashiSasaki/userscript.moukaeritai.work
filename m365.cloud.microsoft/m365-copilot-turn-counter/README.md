# M365 Copilot Turn Counter

## 概要 (Overview)
Microsoft 365 Copilot (m365.cloud.microsoft) の会話において、以下の項目をカウントしてリアルタイムに表示するユーザースクリプトです。

-   **ターンの数**: ユーザーとアシスタントのやり取りの回数。
-   **生成されたアーティファクト**: Copilot ページやリサーチ結果など、生成された特定のコンテンツの数。
-   **アップロードされた画像**: ユーザーが会話に投入した画像の数。

フローティングパネルとしてUIが表示され、ドラッグによる移動も可能です。

## 機能 (Features)
-   **リアルタイムカウント**: MutationObserver を使用して会話の進行を監視し、数値を自動更新します。
-   **フローティングUI**: 画面上の邪魔にならない位置に情報を表示します。
-   **展開/折りたたみ**: 折りたたみ時は最小限のアイコン表示、クリックで詳細情報を表示します。
-   **インストール検知**: サイト上でのインストール状態を自己申告する機能を備えています。

## 使い方 (Usage)
1. スクリプトをインストールします。
2. `m365.cloud.microsoft` のチャット機能を利用します。
3. 画面上に表示されるカウンターで現在の進捗を確認できます。
