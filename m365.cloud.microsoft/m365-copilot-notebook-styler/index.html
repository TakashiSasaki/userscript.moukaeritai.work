M365 Copilot Notebook Styler

概要 (Overview)

Microsoft 365 Copilot ノートブック (m365.cloud.microsoft/chat/ および m365.cloud.microsoft/notebooks/) のUIにおいて、左ナビゲーションペイン、中央ワークスペース、右チャットペインの3つの主要領域の背景色をわずかに変更し、境界を明確にするためのユーザースクリプトです。

デフォルトのモダンUIでは、境界線が曖昧でペイン間の区別がつきにくい場合があるため、このスクリプトは視認性の向上を目的としています。ダークモードとライトモードの両方に馴染むように半透明の色を設定しています。

機能 (Features)

  • ペインの境界色付け: ノートブックUIの主要な3ペイン構造を検知し、それぞれに異なる背景色を適用します。
  • オン/オフ トグルUI: 画面右上に表示されるフローティングUIから、色付け機能の有効・無効をリアルタイムに切り替えることができます。
  • 設定の保存: トグルの状態はローカルストレージに保存され、次回のアクセス時にも維持されます。

使い方 (Usage)

  1. スクリプトをインストールし、M365 Copilot のノートブックページを開きます。
  2. 画面右上に「M365 Pane Styler」という小さなフローティングパネルが表示されます。
  3. トグルスイッチをクリックして色付け機能のオン/オフを切り替えます。
  4. パネルの上部（タイトル部分）をドラッグすることで、パネルの位置を自由に移動できます。
