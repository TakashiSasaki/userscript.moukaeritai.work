# grok-copy-all.user.js 概要

Grokの会話ページでは複数回の会話ターンが表示されています。
ユーザーのメッセージと、Grokからの応答が交互に表示されます。
どちらにもコピーボタンがつけられていて、
クリップボードにコピーすることができます。
全てのターンについて一括してクリップボードにコピーしたいので、
そのために会話の先頭から順にコピーボタンを押していったように
エミュレートして、そのたびにクリップボードにコピーされたテキストを
連接して一つの大きなテキストをクリップボードに保持したいです。

# ユーザースクリプトの仕様 (grok-copy-all.user.js)

`grok-copy-all.user.js` は、Grokの会話ページに「Copy All」ボタンを追加し、以下の手順で自動的に会話内容を収集します。

## 機能

1.  **「Copy All」ボタンの追加**:
    - 画面右上にオレンジ色の「Copy All」ボタンをフローティング表示します。
2.  **コピーボタンの検出**:
    - ページ内にある `aria-label="コピー"` または `aria-label="Copy"` を持つすべてのボタンを上から順に特定します。
3.  **クリップボード操作のインターセプト**:
    - `navigator.clipboard.writeText` 関数を一時的にジャックし、コピーされたテキストをシステムクリップボードに書き込む代わりに、内部のバッファに蓄積します。
4.  **順次クリックエミュレーション**:
    - 特定したコピーボタンを一つずつ順番にプログラムでクリックします。
    - 各クリックの間に一定の待機時間（100ms）を設け、Grokのウェブアプリが反応してクリップボード書き込み関数を呼び出すのを待ちます。
5.  **テキストの結合と出力**:
    - すべてのボタンのクリックが完了した後、蓄積された各ターンのテキストを `--------------------` (区切り線) で結合します。
    - 結合された「全会話テキスト」を最終的にシステムクリップボードに書き込みます。
6.  **完了通知**:
    - ボタンのテキストを「Done!」に変更して完了を知らせます。

## 使用方法

1.  Tampermonkey等のユーザースクリプトマネージャーに `grok-copy-all.user.js` をインストールします。
2.  Grokの会話ページを開きます（ログインが必要な場合があります）。
3.  右上の「Copy All」ボタンをクリックします。
4.  処理中はボタンの色が変わり、完了すると「Done!」と表示されます。
5.  メモ帳などにペーストして、全会話がコピーされていることを確認してください。

## 技術的詳細

-   **Selector**: `button[aria-label="コピー"], button[aria-label="Copy"]`
-   **Method**: `click()` イベント発火 + `navigator.clipboard.writeText` フック
-   **Security**: Cloudflare等のボット対策がある場合、ブラウザの自動操作ツールからはアクセスできないことがありますが、ユーザースクリプトとして人間の操作するブラウザ内で実行する場合は問題なく動作します。
