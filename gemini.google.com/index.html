Gemini App Tools

Google Gemini の体験をより快適に。会話管理、データ出力、UIカスタマイズのための高品質なユーザースクリプト集です。

📦 Recommended Bundle (連携スクリプト群)

以下のスクリプトは、カスタムイベントを通じて相互に連携し、より強力でシームレスな体験を提供します。最大限の機能を発揮するために、一括してインストールすることを推奨します。

  • History Loader 🔄

    Gemini の仮想スクロールを回避し、過去の会話履歴を一番上まで強制的に読み込むための共有モジュールです。インストール状況を示すフローティングUIが画面に表示され、履歴取得中はプログレスを表示するパネルに展開されます。（単体では機能しません）

    Install (v0.1.10)
  • Artifact Exporter Worker ⚙️

    Artifact Exporter のバックグラウンド処理を担当するワーカーです。ドキュメントエクスポートの際のDOM操作や待機処理を分離して安定性を高めます。（単体では機能しません）

    📥 Install (v0.2.16)
  • Artifact Exporter 📦

    サイドバーに表示される Article 形式のアーティファクトを Google ドキュメントにまとめてエクスポート。One Click Delete との併用で、エクスポート完了後に会話を自動削除する連携も可能です。

    Install (v0.4.23)
  • Export to Docs 📄

    回答内容を美しく整形して Google ドキュメントへ出力。「1-Turn Auto Export」機能により、One Click Delete と併用して1ターンのみの会話をエクスポート後に即座に削除する流れるような操作が可能です。

    Install (v0.4.48)
  • One Click Delete 🗑️

    ヘッダーメニューの奥にある「削除」機能をフロントへ引き出します。サイドバーを操作することなく、現在の会話をワンクリックまたはキーボードショートカットで即座に削除できるようになります。

    Install (v0.3.11)
  • Auto-Select Next ⏭️

    現在閲覧中の会話を削除した際、自動的に会話リストの次のアイテムを選択して表示します。削除のたびにトップページに飛ばされる標準の挙動を防ぎ、スムーズな会話の整理を可能にします。

    Install (v0.2.41)
  • Turn Counter 🔢

    ターン数、文字、画像、コード、テーブル、各アーティファクト数をリアルタイムに計測。主に Gemini の各モデルのコンテキストウィンドウ消費量を見積もるために設計されています。

    スクリプトをインストール (v0.4.50)

🧩 Standalone Scripts (単独動作スクリプト)

これらのスクリプトは単独で動作し、個別にインストールして使用できます。

  • Saved Info Helper 📋

    Gemini の「保存済みの情報（カスタム指示）」画面に連番とコピーボタンを追加します。複数の指示を使い分ける際の視認性を高め、ワンクリックで内容をクリップボードにコピーできます。

    Install (v0.2.15)
  • Profile Badge 📛

    Google Gemini のプロファイル覧に、お好みの絵文字やテキストでカスタムバッジを表示します。複数のアカウントや用途を視覚的に区別するのに役立ち、自分好みにカスタマイズできます。

    Install (v0.1.25)
  • Auto-Scroll 📜

    サイドバーを自動で末尾までスクロールし続け、過去の膨大な会話履歴をすべて読み込みます。全履歴のバックアップや検索の準備作業として、手動スクロールの手間を大幅に削減します。

    Install (v0.2.44)
  • Search Snippet Helper 🔢

    検索結果一覧の各会話カードにタイトルへ連番を表示し、視認性を向上させます。タイトルが似通った過去の会話が多く並ぶ場合でも、番号によって目的の会話を素早く特定・参照できるようになります。

    Install (v0.1.19)
  • Prompt Injector 💉

    カスタムイベント経由で Gemini のプロンプトエリアにテキストを注入し、自動送信するスクリプトです。外部システム連携時のプロンプト自動入力やモデル切り替え（高速、思考、Pro）、Canvas有効化に最適です。

    Install (v0.2.8)
