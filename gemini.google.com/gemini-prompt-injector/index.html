Gemini Prompt Injector

Gemini のプロンプトエリアに、カスタムイベント経由で任意のプロンプトを注入し、自動送信するユーザースクリプトです。

機能

  • カスタムイベント gemini-inject-prompt をリッスンし、指定されたテキストを入力。
  • 入力後、送信ボタンを自動的にクリック。
  • カスタムイベント gemini-switch-model をリッスンし、モデル切り替えを自動化。
  • Canvas機能の有効化、プロンプト送出の自動化に対応。

使用方法

他の拡張機能やコンソール、別のユーザースクリプトから、以下のようにカスタムイベントを発火させることで利用します。

プロンプトの注入と送信

document.dispatchEvent(new CustomEvent('gemini-inject-prompt', {
    detail: { prompt: "こんにちは、Gemini!" }
}));

モデルの切り替え

detail.model に "flash", "thinking", "pro" のいずれかを指定。

document.dispatchEvent(new CustomEvent('gemini-switch-model', {
    detail: { model: "thinking" }
}));

連携スクリプト

受信（使われる側）

  • gemini-inject-prompt: プロンプトエリアへテキストを注入。
  • gemini-send-prompt: 注入されたプロンプトを自動送信。
  • gemini-switch-model: モデルを切り替え。
  • gemini-enable-canvas: Canvas機能を有効化。
