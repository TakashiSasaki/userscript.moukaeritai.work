# Gemini Artifact Exporter

## 概要

Google Gemini のサイドバーに表示されるすべての「Article」タイプのアーティファクトを、Google Docsに一括でエクスポートするユーザースクリプトです。

Geminiの会話ページ（例: `https://gemini.google.com/app/xxxxxxxx`）を開くと、設定用のコントロールパネルが画面上に表示されます。

## インストール

1.  お使いのブラウザに [Tampermonkey](https://www.tampermonkey.net/) などのユーザースクリプトマネージャーをインストールします。
2.  [gemini-artifact-exporter.user.js](gemini-artifact-exporter.user.js) をクリックし、表示される手順に従ってスクリプトをインストールします。

## 主な機能

-   サイドバー内のすべての「Article」アーティファクトを自動でGoogle Docsにエクスポート
-   ドラッグで移動可能なコントロールパネル
-   実際のエクスポートを行わずに動作をテストできる「Dry Run」モード
-   エクスポート処理間の待機時間をカスタマイズできるクールダウン設定
-   処理状況をリアルタイムで確認できるログパネル

## 使い方

1.  アーティファクトを含むGeminiの会話ページを開きます。
2.  画面に「Artifact Exporter」というコントロールパネルが表示されます。
3.  必要に応じてパネルでオプション（Dry Run、クールダウン時間など）を設定します。
4.  **`Export All Articles`** ボタンをクリックすると、エクスポートが開始されます。
    -   **注意**: 確認ダイアログは表示されません。ボタンをクリックすると即座に処理が始まります。
5.  「Show Log Panel」を有効にしている場合、詳細な進捗がログパネルに表示されます。

## コントロールパネルの各機能

-   **`Export All Articles` ボタン**: すべての記事アーティファクトのエクスポート処理を開始します。
-   **`Dry Run` チェックボックス**: オンにすると、実際のエクスポート（最後のクリック）を行わずに全工程をシミュレートします。テストに便利です。
-   **`Show Log Panel` チェックボックス**: オンにすると、処理の詳細ログを表示するパネルの表示/非表示を切り替えます。パネルにはログをクリップボードにコピーするボタンもあります。
-   **`Cooldown (s)` 入力欄**: 各アーティファクトを処理した後の待機時間を秒単位で設定します。ネットワークへの負荷を軽減するための設定です。最小値は3秒です。

## 注意事項

-   エクスポートはGeminiの標準UI（Share → Export to Docs）を自動操作するものです。そのため、事前にGoogleアカウントにログインしており、Google Docsを利用できる状態である必要があります。
-   アーティファクトの数が多い場合、すべての処理が完了するまでに時間がかかります。処理中はブラウザのタブを開いたままにしてください。
