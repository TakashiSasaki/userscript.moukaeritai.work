Gemini 1-Click Export to Docs

Geminiの1ターン会話を対象に、URL一致による自動エクスポートと削除・次会話移動をまとめて扱いやすくするユーザースクリプトです。

Installed: -

依存設定（前提スクリプト）: このスクリプトの全機能を利用するには、以下のスクリプトもインストールして有効にしてください。

  • Gemini Auto-Select Next
  • Gemini 1-Click Delete

目的

標準機能では複数回のクリックが必要な Google Docs へのエクスポートやノートブック追加を、1ターン会話向けの専用パネルと自動判定で扱いやすくします。
本ユーザースクリプトはTampermonkeyでの利用を想定し、ファイル名は gemini-export-to-docs.user.js とします。

経緯

以前作成したスクリプトの課題（DOM要素検出の不安定さ、イベントトリガーの信頼性）を解消するため、ゼロベースで再設計・実装を行う。

ユーザースクリプト情報

  • Match URL: https://gemini.google.com/* （スクリプト内部でURLを監視し、チャットページでのみ動的に有効化されます。現在、/app/ および /gem/ のパス形式に対応しています。）

機能概要

1. 1ターン専用オートエクスポートパネル

  • 表示条件: 会話が1ターン（プロンプト1回、回答1回）のみの場合に、画面右下へ専用パネルを表示します。
  • Auto Export Toggle: Auto Export: Off/On ボタンで URL一致の自動判定と自動エクスポートを開始・停止できます。
  • Eligibility Indicator: トグルの On/Off に関係なく、現在表示中の会話が自動エクスポート条件に適合しているかを Matched / Waiting / Not Matched と短い理由文で表示します。
  • 実行先の複数選択: Google Docs と Notebook を独立して On/Off でき、両方有効な場合は Docs → Notebook → Delete の順で処理します。
  • Notebook title の記憶: 追加先ノートブック名を入力欄に保存し、次回以降も再入力なしで利用できます。
  • 自動削除連動: エクスポート完了後、設定に応じて会話を自動的に削除します。
  • 自動スキップ連動: URL一致条件を満たさなかった会話では、設定に応じて Gemini Auto-Select Next にイベントを送って次の会話へ移動できます。
  • 安全停止: 共通 snackbar 監視で success 以外の通知を検知した場合は、自動エクスポートを停止し、削除・スキップ設定も安全側へオフに戻します。

連携スクリプト

他のユーザースクリプトとカスタムイベントを通じて連携します。

送信（使う側）

  • One Click Delete: 選択した出力先への処理がすべて成功した後に会話を自動削除。
  • Auto-Select Next: URL一致条件を満たさなかった1ターン会話で gemini-auto-select-next:request-next を送信し、次のアイテム選択を依頼。
