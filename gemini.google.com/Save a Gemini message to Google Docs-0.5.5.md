# Save a Gemini message to Google Docs ユーザースクリプト

## 概要

この「Save a Gemini message to Google Docs」ユーザースクリプトは、Google Gemini のインターフェースに高度なエクスポート機能を追加し、ユーザーが Gemini のメッセージを Google Docs に効率的に保存できるように設計されています。本スクリプトは、クリックイベントの処理をラップし、非同期的な要素の読み込みを待機する `waitForSelector` を活用します。また、絵文字を用いたエクスポートボタンを重複なくインラインおよび既存メニューの隣に動的に挿入します。さらに、アクティブなメッセージを視覚的に強調表示する機能や、スクリプトの動作状況を示すバナーと便利なメニューコマンドも提供します。

## 機能

このスクリプトは、以下の主要な機能を提供します。

-   **スクリプトアクティブバナー**: ページの右下隅にスクリプト名を表示する小さなバナーを固定表示します。これにより、ユーザーはスクリプトが正常にロードされ、アクティブに機能していることを一目で確認できます。
-   **設定のカスタマイズ**: ユーザーがキーボードショートカット（例: `Ctrl+Shift+D`）や、DOM要素のセレクター、非同期処理のタイミングなど、スクリプトの動作に関する様々なパラメータを柔軟に設定できます。
-   **クリックシミュレーション (`simulateClick`)**: 指定された DOM 要素に対して、プログラムによって本物のクリックイベントをシミュレートするためのユーティリティ関数です。これにより、ユーザーインタラクションなしで UI 要素を操作できます。
-   **要素の待機 (`waitForSelector`)**: 特定のセレクターに一致する要素がページの DOM 内に出現するまで非同期的に待機する汎用ユーティリティ関数です。動的にロードされるコンテンツに対応するために不可欠です。
-   **視覚的な強調表示 (`forceHighlight`)**: 指定された DOM 要素の背景色を薄緑色に、枠線をライム色に設定することで、その要素を視覚的に強調表示します。
-   **「Export to Docs」ボタンの検索 (`findExportToDocs`)**: Gemini のインターフェース内で「Export to Docs」というテキストを持つメニュー項目を非同期的に検索し、その要素への参照を返します。
-   **エクスポート処理 (`exportFor`)**: 特定の Gemini 応答コンテナに対するエクスポートロジックの中核を担います。
    -   応答コンテナ内の「その他メニュー」ボタン（`SEL_MENU_BTN`）をプログラムでクリックします。
    -   その後、「エクスポート」ボタン（`SEL_EXPORT_BTN` または `SEL_SHARE_EXPORT`）を見つけてクリックします。
    -   最終的に、「Export to Docs」メニュー項目を特定し、一時的に黄色い背景、赤い枠線、オレンジ色の点線枠線で強調表示した後にクリックし、Google Docs へのエクスポートプロセスをトリガーします。
-   **絵文字エクスポートボタンの作成と挿入**:
    -   「📄」絵文字をテキストとするカスタムエクスポートボタン (`createButton`) を作成します。
    -   `processContainers()` 関数は、ページロード時、スクロール時、ウィンドウサイズ変更時、および DOM の変更時（`MutationObserver` を利用）に呼び出されます。この関数は、各 Gemini 応答コンテナに対して、アバターの隣または既存のメニューボタンの隣にこのカスタムエクスポートボタンを挿入し、重複するボタンが作成されないことを保証します。
    -   現在最も上部に表示されている応答コンテナは、`forceHighlight` 関数によって鮮やかなライム色で強調表示され、その他の表示されているコンテナは点線で強調表示されます。
-   **キーボードショートカット**: `Ctrl+Shift+D` のキーボードショートカットの組み合わせを監視します。
    -   このショートカットが押されると、デフォルトのブラウザアクションとイベントの伝播を防止し、現在表示されている最初の応答コンテナに対して `exportFor` 関数を即座にトリガーし、エクスポートプロセスを開始します。
-   **Tampermonkeyメニューコマンド**: Tampermonkey のユーザーメニューに「Check Save a Gemini message to Google Docs」というコマンドを登録します。このコマンドを選択すると、スクリプトがアクティブであることを確認するアラートが表示されます。

## 動作環境

-   **ターゲットウェブサイト**: このユーザースクリプトは、Google Gemini のアプリケーションページに特化して動作するように設計されています。
    -   **URL パターン**: `https://gemini.google.com/app/*` および `https://gemini.google.com/app`
-   **ブラウザ拡張機能**: このスクリプトは、Tampermonkey や Greasemonkey などのユーザースクリプトマネージャーと組み合わせて使用することを意図しており、これらの環境下でカスタム JavaScript をウェブページ上で実行することができます。

## 技術詳細 (バージョン 0.5.5)

-   **イベント処理のラッピング**: ネイティブのクリックイベントを直接操作するのではなく、独自の `simulateClick` 関数でラップすることで、イベントの伝播制御とカスタマイズ性を向上させています。
-   **非同期処理と要素待機**: `Promise` と `setInterval` を組み合わせた `waitForSelector` 関数により、動的にロードされる DOM 要素の出現を確実に待機し、スクリプトの堅牢性を高めています。
-   **DOMミューテーション監視**: `MutationObserver` を利用して DOM の変更をリアルタイムで監視し、新しい Gemini メッセージがページに追加された際にエクスポートボタンを動的に挿入することを可能にしています。
-   **インライン CSS スタイリング**: `Object.assign(btn.style, ...)` や `el.style.setProperty('property', 'value', 'important')` を用いて、JavaScript から直接 CSS スタイルを適用し、UIのカスタマイズと視覚的なフィードバックを提供しています。
-   **`GM_` 関数群の活用**: Tampermonkey の `GM_registerMenuCommand` を使用して、ユーザーメニューにカスタムコマンドを統合し、スクリプトの使いやすさを向上させています。
-   **パフォーマンス最適化**: `setTimeout` による遅延実行や、`processContainers` 関数内で `offsetParent` をチェックして非表示要素の処理をスキップするなど、パフォーマンスを考慮した設計がなされています。
-   **スコープ内の要素クエリ**: `:scope` セレクターを使用して、特定の親要素内のみでクエリを実行し、DOM 探索の効率を高めています。
