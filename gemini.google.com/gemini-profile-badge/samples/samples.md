# Gemini Dom Samples

Gemini の DOM 構造は頻繁に変更される可能性があります。開発のために、プロファイルアイコン周辺の DOM スナップショットをここに保存します。


## ファイル一覧

### whole-dom.html

Geminiのウェブアプリのページ全体のDOM構造を保存したファイルです。

### toolbar.html

Geminiのウェブアプリの、会話表示部分の上部にある横長のツールバーです。
ユーザーの顔画像はこのツールバーの右方向の外側に位置しているので、
このツールバー内には顔画像はありません。
このツールバー内には余白があるので、そこにバッジを表示します。

## HTMLファイルの前処理ガイドライン

ユーザースクリプトからのDOM操作に影響を及ぼさない要素を削除し、開発効率の向上とファイルの軽量化を図ります。

### 前処理ルール
1.  **テキストノードの制限**: 1000文字を超えるテキストノードは、1000文字未満にトランケート（切り捨て）します。
2.  **不要な要素の削除**: `<script>` 要素および `<style>` 要素をすべて削除します。
3.  **不要な属性の削除**: 値が空文字列（例：`style=""`）である属性を削除します。

### 自動スクリプトの使用
`samples/` ディレクトリで以下のPythonスクリプトを実行することで、上記の前処理を自動的に適用できます。

```bash
pip install beautifulsoup4
python preprocess_samples.py
```
