# Copy CPU benchmark table of Passmark

## スクリプト概要

このTampermonkeyユーザースクリプトは、PassmarkのCPUベンチマークウェブサイト（`https://www.cpubenchmark.net/cpu_list.php`）に、CPUベンチマーク結果をコピーするためのボタンを追加します。このボタンをクリックすると、ベンチマークテーブルの内容がTSV（タブ区切り値）形式でクリップボードにコピーされ、スプレッドシートアプリケーションに簡単に貼り付けることができます。

## 主な機能と動作

-   **ワンクリックでのデータ抽出**: PassmarkのCPUリストページに「Copy it to the clipboard」ボタンを挿入します。
-   **TSV形式への変換**: ボタンがクリックされると、スクリプトはメインのCPUベンチマークテーブル（`#cputable`）を処理し、その行とセルからすべてのテキストコンテンツを抽出します。抽出されたデータはTSV形式に整形されます。各セルの内容はタブ文字（`	`）で区切られ、各行は改行文字（`
`）で終了します。
-   **クリップボード連携**: Tampermonkeyの`GM_setClipboard` APIを利用して、生成されたTSVデータを直接システムクリップボードに配置します。
-   **ユーザーフィードバック**: コピーされた行数をユーザーに通知する`alert`メッセージを表示します。
-   **遅延セットアップ**: ページコンテンツ（ベンチマークテーブルを含む）が完全にロードされることを確実にするため、ボタンは5秒の遅延後にページに追加されます。

## スクリプトの目的

このスクリプトは、PassmarkのCPUベンチマークデータ分析プロセスを大幅に効率化します。手動での選択、コピー、整形の手間を省き、スプレッドシートソフトウェアへの効率的なデータインポートを可能にします。

## 技術詳細

-   **Tampermonkey API**:
    -   `GM_setClipboard`: 整形されたTSVデータをシステムクリップボードにコピーするために使用されます。
-   **DOM操作**: `document.querySelectorAll`, `document.createElement`, `appendChild`, `addEventListener`などを用いて、ページ要素の追加、変更、イベントリスナーの設定を行います。

## 使用方法

1.  Tampermonkeyまたは同様のユーザースクリプトマネージャーをブラウザにインストールします。
2.  このスクリプトをインストールします。
3.  PassmarkのCPUリストページ（`https://www.cpubenchmark.net/cpu_list.php`）にアクセスします。
4.  ページ上部に「Copy it to the clipboard」ボタンが表示されます。
5.  このボタンをクリックすると、CPUベンチマークテーブル全体がTSV形式でクリップボードにコピーされます。
6.  コピーしたデータは、ExcelやGoogleスプレッドシートなどのスプレッドシートアプリケーションに直接貼り付けることができます。
