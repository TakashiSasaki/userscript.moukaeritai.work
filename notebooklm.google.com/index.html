NotebookLM Utilities

NotebookLM の操作性を向上させるユーザースクリプト集です。ソース管理やアーティファクトの操作を効率化します。

  • Source Management Tools 🛠️

    ソースパネルに連番表示、クイックリネーム、クイック削除ボタンを追加し、ソース管理を効率化します。

    Install (v0.1.14)
  • Artifact Delete Button 🗑️

    アーティファクト（Studio）パネルに、各アーティファクトを直接削除するためのボタンを追加します。

    Install (v0.1.1)
