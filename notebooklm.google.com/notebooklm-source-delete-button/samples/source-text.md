# source-text.html の構造説明

このファイルは、NotebookLM のソースパネルにおける「テキスト形式のソース項目」の DOM 断片です。

## 主要な構成要素

**包含関係**: この要素は `div.scroll-area-desktop` の直接の子要素として配置されます。

1.  **ルートコンテナ (`.single-source-container`)**:
    - 各ソース項目の親要素。`tabindex="0"` を持ち、フォーカス可能です。
    - 前処理により Angular 固有の属性や動的クラス（`ng-tns-*` 等）が除去され、クリーンな状態になっています。
2.  **タイトルカラム (`.source-title-column`)**:
    - `.source-title` クラスを持つ要素内に、ソースのタイトル（例: "epas tsv"）が含まれます。
    - `aria-label="Source title"` が付与されており、ツールチップのトリガーとしても機能します。
3.  **チェックボックスコンテナ (`.select-checkbox-container`)**:
    - `mat-checkbox` を含み、ソースの選択状態を管理します。
    - 内部には `input[type="checkbox"]` が含まれており、プログラムからの状態操作やイベント監視の対象となります。

## 削除ボタンの実装における意義

この断片は、テキストベースのソース項目に対して、削除ボタンをどの位置に挿入するのが最適かを検証するために使用します。

- **挿入ターゲット**: `.select-checkbox-container`
- **利点**: ユーザーがソースを選択（チェック）する動作の近くに削除ボタンを配置することで、直感的な操作感を提供できます。
- **共通性**: Markdown や URL 形式のソースと `.single-source-container` 以下の基本構造が完全に共通しているため、単一のロジックで全形式のソースに対応可能であることを裏付けています。
**実装上の注意**: テキストソースの場合、タイトルが短くなる傾向があるため、削除ボタンの挿入によってレイアウトが崩れないよう、コンテナの幅（`min-width`）に配慮が必要です。
