NotebookLM Source Delete Button

NotebookLM のソースパネルに、ソースの管理を効率化するための機能を追加するユーザースクリプトです。

主な機能

  1. ソースの連番表示:
    • 各ソースアイテムの左上に連番を表示し、ソースの総数や順序を把握しやすくします。
  2. クイックリネームボタン (✎):
    • ソースアイテムにリネームボタンを追加します。クリックすると、ネイティブの「Rename source」メニューを自動的に呼び出します。
  3. クイック削除ボタン (×):
    • ソースアイテムに削除ボタンを追加します。クリックすると、ネイティブの「Remove source」メニューの選択から、確認ダイアログの確定（Delete）までを自動的に実行します。

実装の仕組み

  • 自動化シーケンス:
    • NotebookLM のネイティブ UI は、ホバー時のみ「More」ボタンが表示される仕様であるため、スクリプト側で mouseenter/mouseover イベントをエミュレートしてボタンを出現させます。
    • メニューの出現やダイアログの表示を async/await とポーリング（定期的な要素確認）によって待機し、確実に操作を完了させます。
  • パフォーマンスへの配慮:
    • SPA（Single Page Application）の遷移に対応するため、setInterval による監視を行っていますが、/notebook/ 以下のURLでのみ主要なロジックが動作するように制限されています。
  • 互換性と保守性:
    • バージョンチェック API を実装しており、外部からのバージョン確認が可能です。
    • 特定のクラス名が変更された場合に備え、テキスト内容によるフォールバック検索ロジックを備えています。

開発ルール

  • バージョン管理:
    • 初期バージョンは 0.1.0 とし、変更ごとにパッチレベルをバンプアップします。
  • URL マッチング:
    • https://notebooklm.google.com/notebook/* で有効になります。
  • API 実装:
    • バージョンチェックのための userscript-check-version イベントに応答する API を実装しています。
    • 開発用ポータルサイトでのインストール検知用ガードを実装しています。
