YouTube App Tools

YouTube のプレイリスト管理や視聴体験をより快適に。大規模なリストの整理や自動化を支援するユーザースクリプト集です。

  • Playlist Saver 📺

    プレイリストの動画IDを記録・管理。フィルタリング等のUI機能は独立したスクリプトに分離されました。バックグラウンドで動作します。

    Install (v0.2.53)
  • Playlist Scroller 📜

    プレイリストの自動スクロール専用ツール。大量の動画があるリストをバックグラウンドで読み込み続けるのに最適です。Saverと併用可能。

    Install (v0.1.11)
  • Playlist Filter 🔍

    プレイリストのフィルタリング、スキャン済み範囲（Range）の状態表示を提供します。Saverと連携して動作します。

    Install (v0.1.13)
  • Playlist Remover 🗑️

    プレイリスト内の不要な動画（視聴済みの動画など）を一括削除するツール。フィルタと連携して安全に削除できます。

    Install (v0.1.31)
  • Playlist Lite ⚡

    プレイリストのサムネイルを非表示にして軽量化するツール。大量の動画があるリストの操作を快適にします。

    Install (v0.1.8)
