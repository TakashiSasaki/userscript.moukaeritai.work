# YouTube Playlist Lite - Developer Notes

このドキュメントは、`youtube-playlist-lite.user.js` の開発・保守を行うAIエージェントおよび開発者のための技術的なメモです。

## コア機能と戦略

### サムネイルの処理モード
このスクリプトは、YouTubeプレイリストの軽量化のために2つのアプローチを提供しています。

1.  **CSSによる非表示 (`visibility: hidden` / `display: none`)**:
    -   **メリット**: 安全で、いつでも瞬時に元に戻せます。レイアウト崩れのリスクが低いです。
    -   **デメリット**: DOM要素自体は存在し画像も読み込まれる（またはリクエストされる）可能性があるため、メモリ削減効果は限定的です。
    -   **実装**: `#img` や `ytd-thumbnail` に対してスタイルを適用します。

2.  **DOMからの削除 (Force Remove)**:
    -   **メリット**: 画像要素 (`img`) をDOMツリーから物理的に削除するため、メモリ使用量を確実に削減できます。数千件の動画リストで特に有効です。
    -   **デメリット**: 元に戻すにはページのリロードが必要です。
    -   **実装**: `MutationObserver` を使用して、新しく追加されたサムネイル要素を検知し即座に `remove()` します。

### SPAナビゲーションへの対応
YouTubeはSPA（シングルページアプリケーション）であるため、URLが変わってもページ全体のリロードは発生しません。
-   **`yt-navigate-finish` イベント**: ページ遷移（例：別のプレイリストへの移動）を検知するためにこのイベントを使用しています。イベント発火時に `init()` を再実行し、パネルの再描画や設定の再適用を行います。
-   **クリーンアップ**: 新しいページに遷移した際、古いパネルが残留しないようにチェックし、必要に応じて再生成するロジックが含まれています。

## データ永続化

### `GM_setValue` / `GM_getValue`
ユーザー設定（モード選択、パネルの開閉状態、パネルの位置）は Tampermonkey のストレージ機能を使用して永続化しています。
-   **パネル位置**: ドラッグ＆ドロップで移動した位置 (`top`, `left`) を保存し、次回ロード時にその位置に復元します。これはユーザー体験にとって重要です。

## サンプルHTMLの前処理

`samples/` 配下のDOMスナップショットは、他プロジェクトと同様の前処理を必ず実施してください。
-   **手順**: 他プロジェクトと同じ `preprocess_samples.py` を `samples/` に一時的に置き、`samples/` ディレクトリで `python preprocess_samples.py` を実行してからスクリプトは削除します。
-   **処理内容**: `<script>/<style>` とHTMLコメントの削除、空属性の削除、長いテキストノードの1000文字程度への切り詰め、`<svg>` の子要素削除（`svg` タグ自体は残す）。

## 今後の改善点

-   **メモリ解放の最適化**: 現在のDOM削除ロジックで十分か、あるいはYouTubeのVirtual Scrollerが生成する要素に対してより積極的な介入が必要か、使用状況に応じて検討してください。
-   **サムネイル以外の軽量化**: プレビュー動画の自動再生停止や、メタデータの簡略化など、さらなる軽量化オプションの追加も考えられますが、スクリプトの複雑化とのトレードオフを考慮してください。

## インストール/バージョン検知API
- `index.html` は `userscript-ping` を送信し、各ユーザースクリプトが `userscript-check-installed` を `dispatchEvent` して応答することで検知します。
- 受信側は `data-script-name` と `@name` の一致で対象ボタンを特定します。
- `Install (vX.Y.Z)` の表記からバージョンを抽出し、セマンティックバージョン比較で `Update` / `Installed` を切り替えます。
