# Mineo Gift Code Automatic Copy-and-Paste ユーザースクリプト

## 概要

この「Mineo Gift Code Automatic Copy-and-Paste」ユーザースクリプトは、Mineo のパケットギフト関連ページにおける一連の操作を自動化し、ユーザーエクスペリエンスを大幅に向上させます。具体的には、ギフトコードの自動コピー・ペースト、ギフト容量の自動入力、および「ゆずるね。」の自動宣言を行います。また、ページ上の不要なUI要素を非表示にすることで、視覚的なノイズを減らし、主要な情報に集中できるようにします。

## 機能

このスクリプトは、以下の主要な機能を提供します。

-   **ギフトコードの自動処理**:
    -   **発行完了時の自動保存**: 「パケットギフト発行完了」ページが表示されると、ページからギフトコードを自動的に抽出し、クリップボードにコピーします (`GM_setClipboard`)。同時に、ユーザーへの通知 (`GM_notification`) と、スクリプトのストレージ (`GM_setValue("giftCode")`) にギフトコードを保存し、そのコードがまだ使用されていないことを示すフラグ (`GM_setValue("redeemed", "no")`) を設定します。
    -   **受取完了時のステータス更新**: 「パケットギフトお受け取り完了」ページが表示されると、コードが使用済みであることを示すフラグ (`GM_setValue("redeemed", "yes")`) を設定し、今後の処理に利用します。
    -   **入力ページでの自動ペースト**: ギフトコード入力ページ（特定の `h1` テキストと `packetGiftCode` 入力フィールドで識別）において、スクリプト内に保存されている未消費のギフトコードがあれば、自動的にその入力フィールドにペーストします。
    -   **ギフト容量の自動入力**: ギフト容量入力フィールド（`packetGiftYoryo`）には、自動的に「9999」という最大値を入力します。
-   **「ゆずるね。」の自動宣言**:
    -   ページ読み込み後、2秒のわずかな遅延の後に、「ゆずるね。を宣言する」というテキストを持つボタンが存在すれば、スクリプトが自動的にそのボタンをクリックして宣言を行います。
-   **UIの調整と最適化**:
    -   **不要要素の非表示化**: パケットチャージに関連する要素（`div.boxCharge01`、`div#lotation_banner_navi`）や、グラフ表示（`#graph_bg`）、キャプション、レジェンド、詳細エリア内の特定のボックス、ページステータス表示、h1見出しなど、Mineoページ上の様々な視覚的に不要な要素を、CSSを適用して非表示にします。これにより、よりクリーンなインターフェースを提供します。
-   **Tampermonkeyメニューコマンド**:
    -   Tampermonkey のメニューに、保存されているギフトコードと「redeemed」ステータスをアラート表示するためのカスタムコマンドを登録します。これにより、ユーザーはスクリプトの状態を手動で確認できます。

## 動作環境

-   **ターゲットウェブサイト**: このユーザースクリプトは、Mineo のMVNOコントロールパネルの特定のページで動作するように設計されています。
    -   **URL パターン**: `https://my.mineo.jp/mvno_cp/*.action`
-   **ブラウザ拡張機能**: このスクリプトは、Tampermonkey や Greasemonkey などのユーザースクリプトマネージャーで使用することを意図しており、これらの環境でカスタム JavaScript を実行できます。

## 技術詳細 (バージョン 0.4.20220831.1)

-   **DOMセレクタの利用**: `document.querySelector` を使用して、ページ上の特定の `h1` 要素、`p` 要素、`input` 要素などを正確にターゲットにしています。
-   **`GM_` 関数群の活用**: Tampermonkey/Greasemonkey が提供する `GM_setClipboard` (クリップボード操作), `GM_notification` (通知表示), `GM_setValue`/`GM_getValue` (スクリプト内ストレージ), `GM_registerMenuCommand` (メニューコマンド登録), `GM_addStyle` (CSS追加) といった強力な API を活用しています。
-   **遅延実行**: `setTimeout` を使用して、DOMの変更や他のスクリプトの実行を考慮し、処理を適切なタイミングで実行しています。
-   **正規表現によるデータ抽出**: `innerText.match("[A-Z][A-Z][A-Z][A-Z][0-9][0-9][0-9][0-9]")` を使用して、ページからギフトコードのパターンを抽出しています。
