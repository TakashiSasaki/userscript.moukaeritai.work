# 目的

GeminiのウェブアプリケーションはSPAである。
SPAのUI上で、会話の特定のターンまたはキャンバスをGoogle Docsにエクスポートする機能が標準で提供されている。
しかしこれを使うために複数回のクリックが必要である。
この操作を簡便にするために、1クリックでGoogle Docsへのエクスポートを行うショートカットボタンを追加するのが、
このユーザースクリプトの目的である。
このユーザースクリプトはTampermonkeyで使われる。
このユーザースクリプトのファイル名は gemini-export-to-docs.user.js である。

# 経緯
目的を達成するためのユーザースクリプトとしてすでに
「ワンクリック高速エクスポート (Gemini-Canvas)-1.--SPAルーティングに対応したURL変更監視を追加.user.js」
というスクリプトを作成したが、DOMからの要素の検出をより安定させたり、イベントのトリガーのタイミングをより改善したいので、あらためて gemini-export-to-docs.user.js を作成する。

# SPAのDOM
対象となるSPAはDOMが変化するので、
いくつかのパターンを sample1.html, sample2.html, sample3.html として提供する。
それぞれのHTMLにおいて、エクスポートのためのボタンがどのようなセレクタでどのようなHTML断片として表現されているかを、sample1.md, sample2.md, sample3.md として提供する。

# ショートカットボタンの配置

ショートカットボタンは、特定のターンの応答を対象とする場合はそのターンの応答文の開始行の右上に配置する。
キャンバスの内容をエクスポートする場合は、そのキャンバスを開くためのボタンが表示されているターンの応答文の開始行の右上に配置する。
