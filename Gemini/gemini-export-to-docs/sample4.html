1. 研修プログラムの全体像

提供された資料に基づき、令和7年度（2025年度）のデジタル活用研修は、全職員を対象とした「基礎・マインド醸成（オンデマンド）」と、事務系職員を対象とした「実務・スキル習得（ハンズオン）」の2つの主要なトラックで構成されています。

2. デジタル活用研修（オンデマンド型）

本研修は、IPA（情報処理推進機構）および経済産業省が定める「DXリテラシー標準」に基づき、DXの重要性や基礎知識を習得することを目的としています 。

2.1 実施日時・期間

  • 期間: 令和7年（2025年）5月7日（水）～ 9月30日（火）

    • 注記: 当初案では9月30日（金）との記述がありましたが 、2025年のカレンダー（9/30は火曜日）および修正版資料 に基づき上記と特定されます。

  • 時間: 期間中、任意の時間に受講可能（毎週15分程度の学習を想定） 。

2.2 実施方法

  • プラットフォーム: 愛媛大学Moodle4 (LMS) を使用したe-learning形式 。

  • 受講フロー:

    1. Moodle4へログイン（愛媛大学シングルサインオンを使用） 。

    2. コースカテゴリ「2025年度・教職員向けコース」から『令和７年度前学期デジタル活用研修』を選択 。

    3. 「私を登録する」をクリックして自己登録を行う 。

  • 構成: 全20週〜21週のプログラム 。

    • イントロダクション（1週）

    • DXリテラシー標準入門／DX入門（7週）

    • データサイエンス・AI入門（7週）

    • 情報倫理（5〜7週）

3. 業務効率化のためのMicrosoft 365ハンズオン研修（対面・ハイブリッド型）

本研修は、Teams、Copilot、PowerAutomateなどのツールを実際に操作し、業務プロセスの自動化や効率化を実践することを目的としています 。

3.1 実施日時

  • 基本スケジュール: 火曜日 午前9時〜（要項案による記述） 。

    • 注記: 具体的な開催日程は「別紙」参照とされていますが、会場の例外指定から以下の特定日付が確認できます 。

  • 特定されている開催日:

    • 9月20日（会場変更あり）

    • 10月28日（オンライン開催）

    • 11月19日（会場変更あり）

3.2 実施方法・場所

基本的には対面形式（ハンズオン）で実施されますが、日程により実施形態や会場が異なります。

  • 基本会場: 大学本部5階 第2会議室 。

  • 例外的な会場・実施形態:

    • 9月20日: メディアホール（対面）

    • 10月28日: オンライン開催

    • 11月19日: 南加記念ホール（対面）

  • 必要環境（受講者持参）:

    • ノートパソコン（Windows 11推奨）

    • Microsoft 365アカウント（職場用）へのアクセス権

    • Webカメラ・マイク（Teams会議用）

3.3 カリキュラム構成

全8回の構成が予定されており、各回の内容は以下の通りです 。

  1. Teams（基礎）: ログイン、チャット、会議設定

  2. Copilot: AI支援機能の活用

  3. Forms + PowerAutomate: アンケート作成とワークフロー自動化（前編）

  4. Forms + PowerAutomate: ワークフロー自動化（後編）

  5. OneDrive: ファイル管理と共有設定

  6. Teams（応用）: タスク管理、アプリ連携

  7. SharePoint: ポータルサイト作成

  8. 振り返りとまとめ: 成果発表
