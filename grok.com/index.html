Grok Utilities

Grok の会話管理やナビゲーションを高速化するユーザースクリプト集。ショートカットや一括コピーなど、軽快な操作性を重視しています。

  • Conversation Copy 📋

    会話ページ内の全てのコピーボタンを順に押し、全文を一括でクリップボードへ保存します。

    Install
    v1.3.6
  • Chat History Shortcut ⌨️

    履歴パネルを開いて対象要素を強調表示。深い階層のリンクへ素早くフォーカスします。

    Install
    v0.13
  • Conversation Highlighter 🎯

    X上のGrok会話で対象アイテムを自動検出し、「もっと見る」ボタンを目立たせて操作を補助します。

    Install
  • Grok Conversation Highlighter with Dynamic Selection

    Auto-scroll, dynamically find the highlighted item by its gray wrapper, then click & highlight the “もっと見る” button in cyan

    Install
    v1.20
